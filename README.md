KIWI TOGETHER — 60 stages

GitHub: upload index.html, server.js, package.json to repository root.
Render: Node Web Service; build: npm install; start: npm start.

Preserves existing lobby, chat, joystick and invite UI. Stage 10 features a breaking-room scene; forest starts at stage 11. Subsequent biomes change every 10 stages. Two players can complete all cooperative pad challenges; room cap remains four.

Known limitations: canvas-rendered visual effects (not external art assets), 12 core puzzle rule patterns remixed into 60 stage-specific arrangements; end-to-end multiplayer playtesting not completed.
